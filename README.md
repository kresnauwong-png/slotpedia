# SlotPedia

Website katalog game slot (Pragmatic Play + PG Soft) — file tunggal HTML/CSS/JS, plus panel admin untuk mengatur konten dan pola permainan.

- Buka `index.html` untuk menjalankan.
- Akses panel admin lewat link **Admin** di footer (password default: `SlotPedia2026`).
- Data admin tersimpan di `localStorage` browser; gunakan Export/Import JSON pada panel untuk backup.
- Situs ini katalog informasi — tidak ada transaksi uang asli.
